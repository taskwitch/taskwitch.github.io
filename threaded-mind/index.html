ThreadedMind

An ACT-R inspired multitasking simulator and cognitive load estimation framework.
DownloadDocumentation

Motivation#

Existing cognitive modeling tools are powerful but difficult to configure, extend, and integrate into modern workflows. This project aims to provide a simple, modular framework for cognitive load estimation that researchers and practitioners can adapt to their own tasks.

Work In-Progress#

  • Developing a workload composite score and a workload-aware policy. Human cognitive load as well as working performance are affected by more factors (such as task importance, context switch cost, deadline-risk cost, tardiness). We are trying to find an empirical workload formula and let the simulator optimize scheduling for the minimal workload.
  • Native ACT-R integration. Supporting real and dynamic ACT-R models instead of hardcoded .yaml task description files.
  • Fidelity & robustness check against more experiments datasets.
