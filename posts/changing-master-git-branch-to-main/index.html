Changing Master Git Branch to Main

August 13, 2026

The default Git branch name on my old computer is master, but I am adapting the inclusive language to use main instead of master (as an effort to stop using slavery related words).

If you are an owner of the repository#

In your project folder,

git branch -m master main
git push -u origin main

In GitHub, open your repository settings, and change the default branch to main.

Then, remove the master branch on remote by executing this in your project folder:

git push origin --delete master

Set the default branch in global Git config so that every git init in the future directs you on the main branch.

git config --global init.defaultBranch main

Also, be aware of automations in .github/ folder under your project folder, since changing branch name would sometimes stop them from working.

That said, if you are new to Git / GitHub, the default should already be main.

If you are a collaborator#

After the owner changes the branch name, just fetching the main branch, switching to it, and delete the master branch locally is sufficient.

git fetch origin
git checkout main
git branch -D master
